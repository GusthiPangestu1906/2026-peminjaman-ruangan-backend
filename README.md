# 2026-peminjaman-ruangan-backend

## Deskripsi Proyek
Sistem Peminjaman Ruangan Kampus adalah platform digital yang dirancang untuk mengelola proses peminjaman ruangan secara terpusat. Proyek ini bertujuan untuk mengatasi masalah pendataan manual yang sering tercecer dan sulit dipantau.

## Fitur Utama
* [cite_start]**Pencatatan Peminjaman**: Menambah, melihat, mengubah, dan menghapus data peminjaman[cite: 81, 82, 85].
* [cite_start]**Pengelolaan Status**: Sistem persetujuan peminjaman (Pending, Approved, Rejected)[cite: 87].
* [cite_start]**Riwayat & Penelusuran**: Melacak riwayat peminjaman dengan fitur filter dan pencarian[cite: 98, 101].

## Tech Stack
* [cite_start]**Framework**: ASP.NET Core [cite: 21, 339]
* **Language**: C#
