# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- **UI Overhaul**: Major update to "Cyber/Modern Dark" theme for Frontend.
- **Bento Grid Layout**: Implemented responsive grid layout for the main dashboard.
- **Interactive Components**: Added Toast notifications, Confirmation Modals, and Floating Forms.
- **Filtering**: Added status filtering (All, Pending, Approved, Rejected) in Dashboard UI.
- **Mobile Responsiveness**: Optimized modal and table layouts for mobile devices.

### Changed
- **UX Improvements**: Replaced native browser alerts with custom Toast notifications.
- **Form Handling**: Moved Booking Form to a floating modal for better UX.

### Fixed
- **Responsiveness**: Fixed modal overflow issues on small screens.
